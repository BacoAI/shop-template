# 功能驗收清單

> 2026-09-24。發布給學生之前，先自己把整套點過一遍。
> 網址：電腦 `http://localhost:8788` ／ 手機 `http://192.168.0.225:8788`（要同一個 Wi-Fi）
> 後台：加 `/admin`，帳號 `admin`、密碼 `test1234`
>
> **測的不是「會不會壞」（那我測過了），是「順不順手、看起來對不對」。**
> 覺得哪裡怪就記下來，不用管是不是 bug。

## A. 當一次客人（約 15 分鐘）

**建議用手機測**，因為前台是手機版優先設計的。

- [ ] 首頁三個商品都看得到，名稱、副標、價格對
- [ ] 點商品進得去，照片、介紹、產品說明看起來舒服
- [ ] 配送標籤對（銅鑼燒是冷藏/常溫、餅乾只有常溫、生乳捲只有冷凍）
- [ ] 加購品可以勾、可以調數量
- [ ] 數量按到上限會停住（銅鑼燒 6 個、生乳捲 3 個）
- [ ] 加入購物車後，右下角的數字有變
- [ ] 購物車的日曆：**只有你設定過的日子是亮的**，其他灰掉
- [ ] 點灰掉的日子，會告訴你原因
- [ ] 增減數量、移除商品都正常，金額跟著變
- [ ] 湊到免運門檻時，運費會劃掉變 $0
- [ ] 填地址時，選完縣市和區，郵遞區號自動出現
- [ ] 按「收件人與寄件人相同」，資料自動帶過去而且變成不能改
- [ ] 末五碼沒填時，按下單會擋住並告訴你
- [ ] 下單成功，感謝頁有訂單編號、匯款帳號、金額、明細
- [ ] **重新整理感謝頁** → 應該顯示「沒有可以顯示的訂單」（不該一直停在那）

## B. 當一次店家（約 20 分鐘）

**建議用電腦測**，後台是電腦版排版。

### 商品設定
- [ ] 新增一個自己的商品（名稱、價格、介紹都填）
- [ ] 上傳一張真的照片，前台看得到
- [ ] 改配送方式、改「優先」，存完再打開還在
- [ ] 日曆上點幾天設數量，按儲存
- [ ] **改一個「已經有人訂」的日期，把數量設得比已售少 → 應該被擋下來**
- [ ] 沒按儲存就想離開 → 應該會問你

### 訂單系統
- [ ] 剛才下的單有出現
- [ ] 用姓名、電話、訂單編號分別搜尋，都找得到
- [ ] 篩選付款狀態、訂單狀態，筆數會變
- [ ] 點欄位標題可以排序（點兩次會反過來）
- [ ] 「顯示欄位」可以把不想看的欄位關掉
- [ ] **匯出 CSV，用 Excel 打開看中文有沒有亂碼**
- [ ] 雙擊訂單（手機是單擊）開得起來，所有欄位都能改
- [ ] 改一個數量 → 儲存 → 回商品日曆看「剩餘」有沒有跟著變
- [ ] 打開「版本紀錄」分頁，看得到剛才改了什麼
- [ ] 按「回到這一版」，內容真的退回去
- [ ] 刪除訂單 → 進垃圾桶 → 還原得回來

### 網站編輯
- [ ] 改網站大標題 → 存 → **開前台看有沒有變**
- [ ] 填匯款資訊 → 存 → 開購物車看匯款帳號對不對
- [ ] **把「營業狀態」關掉 → 存 → 開前台，應該變成公告、不能下單**
- [ ] 記得再打開

### 運費與帳號
- [ ] 改冷藏運費 → 存 → 回前台購物車看金額有沒有跟著變
- [ ] 新增一個「一般權限」帳號
- [ ] **登出，用那個帳號登入 → 左邊應該看不到「系統管理」**

## C. 刻意搞破壞（約 10 分鐘）— 這段最容易發現問題

- [ ] **配送衝突**：購物車同時放「生乳捲（只能冷凍）」和「餅乾（只能常溫）」
      → 應該跳紅框、把表單收起來、不給下單
- [ ] **商品下架**：購物車裡放某商品 → 後台把它下架 → 回購物車重整
      → 應該自動移除並告訴你
- [ ] **搶最後一個**：後台把某天數量設成 1 → 前台下單買掉 → 再買一次
      → 應該擋住並說剩幾個
- [ ] **日期太近**：想選明天出貨 → 應該選不到（最少要提前 3 天）
- [ ] **改網址亂逛**：直接打 `/done`（沒下單）→ 應該說「沒有可以顯示的訂單」
- [ ] **沒登入闖後台**：用無痕視窗開 `/admin` → 應該擋在登入頁
